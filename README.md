# Automated_Attendence_System
Traditional methods of attendance taking, such as manual sign-in sheets or roll calls, can be time-consuming, prone to errors, and may lead to cheating or falsification of attendance records.

An automatic attendance system can simplify attendance tracking, reduce administrative burdens, increase transparency, and improve compliance, making it a valuable tool for various organizations and settings. The proposed face detection model detects the faces from every angle without any 3D modeling and the model has an accuracy of 92.38%.
